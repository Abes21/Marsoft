# Centralny panel monitorowania infrastruktury IT i analizy zdarzeń bezpieczeństwa

Projekt stażowy realizowany indywidualnie.

## Cel projektu
Aplikacja internetowa wspierająca administratora w monitorowaniu infrastruktury IT, przeglądaniu logów oraz obsłudze podstawowych alertów bezpieczeństwa.

## Technologie
- Python
- Django
- PostgreSQL
- Docker Compose

## Status
Projekt w trakcie przygotowania.
